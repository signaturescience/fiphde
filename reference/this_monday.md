# Get Monday

This function is a helper to get the date for the Monday of the current
week. The function determines the current week based on epidemiological
week orientation (i.e., week begins with Sunday).

## Usage

``` r
this_monday()
```

## Value

Date for the Monday of the current week.

## Examples

``` r
this_monday()
#> [1] "2026-10-12"
```
