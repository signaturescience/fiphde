# Clean numeric values

This unexported helper is used in the
[ilinet](https://signaturescience.github.io/fiphde/reference/ilinet.md)
function to strip special characters and empty space and convert a
character vector to numeric.

## Usage

``` r
to_num(x)
```

## Arguments

- x:

  Input character vector for which special characters should be stripped
  and converted

## Value

Numeric vector
