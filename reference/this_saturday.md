# Get Saturday

This function is a helper to get the date for the Saturday of the
current week. The function determines the current week based on
epidemiological week orientation (i.e., week begins with Sunday).

## Usage

``` r
this_saturday()
```

## Value

Date for the Saturday of the current week.

## Examples

``` r
this_saturday()
#> [1] "2026-10-17"
```
