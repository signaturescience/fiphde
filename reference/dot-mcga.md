# Make clean column names

This helper is used in
[ilinet](https://signaturescience.github.io/fiphde/reference/ilinet.md)
and
[who_nrevss](https://signaturescience.github.io/fiphde/reference/who_nrevss.md)
functions to clean column names of values returned from the APIs.

## Usage

``` r
.mcga(tbl)
```

## Arguments

- tbl:

  Input `tibble` with columns to rename

## Value

A `tibble` with clean column names
